# 模型训练计划

> 第二阶段更新（2026-09-03）：官网已形成 47 个南京云锦、48 个其他织锦对象级标签证据，但授权均为 `unknown`；仅 6/8 个对象分别通过基础分辨率门槛。因此本计划尚未执行，全部实验指标仍为待训练/待验证。详见 `phase2_training_decision.md`。

当前状态：**未训练；全部指标待训练 / 待验证。**

## 阶段 0：数据门槛

运行 `audit_dataset.py` 校验字段、文件、哈希和统计；由专家审签标签并确认授权。只有 `usable_for_training=true` 且 `usage_scope=training` 的记录可进入后续流程。

## 阶段 1：固定分组切分

使用 `create_splits.py` 按 `source_group_id` 切分 70%/15%/15%。先冻结测试组；任何同源图、派生裁切和增强图不得跨 split。正式实验另保留跨机构外部测试集。

## 阶段 2：Level 1 基线

- 模型：ImageNet 预训练 ResNet-18，二分类头。
- 对照：冻结骨干的线性探测与全量微调。
- 输入：只使用人工复核后的干净图，去除标题、编号卡和网页布局。
- 指标：Accuracy、每类 Precision/Recall/F1、Macro-F1、混淆矩阵；均由真实验证/测试运行生成。
- 诊断：按机构、采集设备、对象类型分层报告，检查数据捷径。

## 阶段 3：Level 2 多标签

- 专家先冻结标签词表和标注指南。
- 模型：共享视觉骨干 + sigmoid 多标签头，损失为 BCEWithLogitsLoss；类别不平衡时只用训练集估计权重。
- 阈值：在验证集逐标签选择，测试集只评估一次。
- 指标：Macro/Micro Precision、Recall、F1、mAP 与逐标签支持数。
- 标签独立来源组不足 20 时不进入训练；建议达到 50 组后才进行试验。

## 阶段 4：可复现与提交

- 固定随机种子、依赖版本、配置、数据清单与 split 文件。
- 保存 checkpoint、训练日志、真实指标 JSON、失败案例和模型卡。
- 重复至少 3 个随机种子，报告均值和波动；不挑最好一次作为唯一结果。
- 在补齐官方技术报告参考大纲后，逐项映射实验内容和证据。
