# 展示版修订说明（2026-10-09）

## 形制依据

本轮展示模型按南京云锦大花楼木织机的公开资料调整：斜身式、束综提花结构；上层花楼由拽花工提经，下层由织手坐在机下完成开口、投梭与打纬，两人协同工作。资料还记载其体量约为 5.6–7 米长、约 1.4–1.8 米宽、约 4–5 米高。

参考来源：

- 中国非物质文化遗产网·中国非物质文化遗产数字博物馆：《南京云锦木机妆花手工织造技艺》
- 南京市机关事务管理局：《锦上有芳华》
- 南京大学艺术实验室 ZHI 艺：《地纬彩纬｜云锦》
- 南京江南丝绸文化博物馆：《南京云锦史上首部“色谱标准”发布》

## 本轮修订

- 展示背景从近黑色改为暖灰棕渐变，并提高织机木构件、金线、人物衣着和织物的轮廓光，解决模型与背景融合的问题。
- 移除叠加在基础人物上的第二组衣袖/衣服覆盖层，取消会被误读为“额外手臂”的金色关节点。
- 移除两个没有工位职责的背景人物，只保留上层拽花工和下层织手，符合两人协同操作的核心关系。
- Exhibition Mode 不再周期性重建 iframe；连续动画由 WebGL 内部时间线保持，减少视频式展示中的跳帧与切镜。
- 保留教学状态、模拟信号和“非尺寸认证机械复原”的边界说明。

## v23 展示增强

- 将提花控制球、流动提示球和关节球改为非球形机构标记或隐藏，避免观众把提示符号误认为织机零件。
- 展示模式扩大提经、开口、投梭、打纬和卷取动作幅度。
- 将织物改为长尺寸、细分网格的软布面，加入连续波动、折痕和长布面出布循环。
- Exhibition Mode 持续产生新的织造段落，不在一小块布面完成后停止。

## v24 同步循环修订

- 参考现场资料将一次循环固定为：拽花提经 → 保持梭口 → 织手投梭 → 筘框打纬 → 间歇卷取。
- 上层拽花工、下层织手、经线开口、梭子、筘框、卷取轴和布边共用同一 16 秒循环时钟。
- 每完成一次卷取才增加一段可见布长，连续累计 24 纬后再进入下一展示段，不再让整块布料无逻辑地循环。
