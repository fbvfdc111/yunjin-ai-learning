# Phase 6.2 AI文化助手相关性修复

## 修复问题

- `云锦是什么？` 原先因为只写简称，不能命中 `南京云锦是什么？` 的证据条目。
- `南京云锦的传统织造工艺是什么？` 原先会被宽泛的 `南京云锦 + 什么` 基本介绍条目抢答，返回非遗名录信息，而不是织造工艺流程。

## 最小修改

- 在回答检索前加入简称同义词：问题中出现 `云锦` 但没有 `南京云锦` 时，仅在本地检索判断中补全为 `南京云锦`。
- 加入工艺/流程意图检查：`传统织造`、`手工织造`、`织造工艺`、`工艺流程`、`工序`、`主要环节` 等问题只允许相关工艺流程条目进入候选。
- 在 `KB003` 增加 `南京云锦 + 织造 + 工艺`、`传统 + 织造 + 工艺` 两组回答触发词。
- 保留证据约束和拒答：没有可回答条目或来源不完整时，仍返回 `证据不足`，不会绕过知识库补写。

## 回归结果

- `云锦是什么？` -> `KB001`
- `什么是南京云锦？` -> `KB001`
- `南京云锦的传统织造工艺是什么？` -> `KB003`
- `南京云锦的制作流程有哪些主要环节？` -> `KB003`

本次未声称真实调用 Dots，也未更改 Dots API 路径、模型名或 provider 配置。
