## 证据规则与对象构成

本轮正式 metadata 共 95 个对象：

- 40 个南京云锦：来自官网“云锦类1：540套”清册，PDF标题为“南京云锦 博物馆藏品清册（云锦类）”，每个对象有独立登记号；
- 40 个其他织锦：来自官网“非云锦类1：1028套”清册，且对象原始名称明确包含“锦”；
- 7 个南京云锦艺术精品：官网栏目说明明确指向南京云锦研究所出品的云锦艺术品，并列出作品名；
- 8 个其他织锦：世界织锦栏目原名明确为泰国锦、埃及织锦或土耳其织锦。

因此确认南京云锦 47 个，确认其他织锦 48 个，未知 0 个，95 个均有可追溯的官网标签证据。本轮没有把只凭视觉外观或仅凭“来自博物馆官网”推测的对象纳入正式对象表。

## 可追溯关系

`data/metadata/official_metadata.csv` 为主索引。每行包含 `object_id/source_group_id`、URL、页面标题、官网原名、登记号、类别原文、采集日期、类别、显式工艺/纹样名称、证据文件、候选主体图、图片尺寸、哈希、泄漏风险与授权状态。

清册对象的链路为：官方 PDF URL → 完整清册页证据 → 登记号 object_id → PDF 内嵌主体缩略图。网页对象的链路为：栏目 URL → 分段网页截图 → 网页作品名 object_id → 官网主体图。
