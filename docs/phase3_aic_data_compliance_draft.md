# AIC 参赛数据合规说明（草稿）

> 本文为项目材料草稿和工程合规记录，不构成法律意见；正式提交前应由主办方、数据权利人及合规人员复核。

本项目将“来源证据”与“训练授权”分开管理。南京云锦博物馆官网收集的 95 个对象被定义为 Official Evidence Database，仅用于验证对象身份、类别、名称、纹样/工艺候选标签和数据治理研究。官网可访问、网页含图片或馆方拥有藏品，均不被推定为允许复制、机器学习训练、模型发布或参赛展示。因未发现覆盖上述用途的明确许可，这 95 个对象的 `authorization_status` 均保持 `unknown`，未进入正式训练集。

公开网络候选按文件记录原始 URL、作者/机构、许可证名称和链接、许可证据、抓取日期、分辨率、对象与标签证据。仅在许可明确、标签可靠、对象独立、图像质量达标且无明显文字/来源捷径时，才将 `usable_for_training` 标为 `true`。CC BY/CC BY-SA 资源须保留署名、许可链接及修改说明；CC BY-SA 的衍生和分发义务将在具体发布形式确定后再次核验；CC0/Public Domain 状态仍保留来源和对象记录。

截至 2026-09-04，可直接训练的南京云锦对象为 0，其他织锦对象为 3，两类及来源结构均不满足正式训练条件。项目没有使用授权不明的官网图片训练，也未生成 Accuracy、Precision、Recall、F1、Loss、混淆矩阵或模型权重。所有实验指标保持“待训练 / 待验证”。

若后续取得书面授权，将把授权文件、适用对象清单、许可范围、期限、署名与再分发条件作为版本化证据保存；按 `object_id/source_group_id` 分组划分训练、验证和测试，并披露外部数据、预训练模型、第三方算法及许可证。
