# Phase 4 AIC 技术创新点草稿

> 草稿仅描述当前代码已经实现或明确标为待配置的能力；不包含用户量、效果、准确率、专家评价或授权推定。

## 1. 从不可训练约束反推可验证 AI 路线

项目没有用极少且来源混杂的数据制造分类指标，而是把“0 个合法可直接训练的南京云锦对象”转化为架构约束：视觉理解负责观察，文化知识库负责事实，检索层负责连接，界面负责披露不确定性。这使系统在没有监督权重时仍有真实、可运行的文化学习价值。

## 2. 三层语义隔离

界面与数据结构显式分离：

1. 可复算的视觉统计或用户可观察描述；
2. 多模态模型的疑似元素推测；
3. 带 source_id 和证据等级的文化事实。

这种隔离减少“看起来像”被误写成“文化事实”或“专业鉴定”的风险。

## 3. 证据优先的轻量 RAG

本地 RAG 不依赖外部向量服务，返回稳定知识 ID、匹配项、来源与证据等级；无证据时拒答。它适合离线比赛演示，也便于评委逐条追溯事实。后续可更换检索器，但回答契约保持不变。

## 4. 数据治理资产直接成为产品能力

Phase 2/3 的 95 个官网对象没有被降格为训练素材，而是以 Official Evidence Database 参与对象名称关联。系统仅展示 metadata 与授权状态，避免把公开可访问误当作可训练/可再展示。

## 5. 双 provider 与诚实降级

本地 fallback 已可运行，输出颜色、边缘和镜像相似性；外部多模态 provider 提供更丰富观察的接口。未配置 API 时明确失败并引导切换，本地结果也明确不是分类模型。该设计允许现场无网络/无 Key 时继续完成核心流程。

## 6. 与论文 Digital Heritage Ecosystem 的边界

本阶段真实实现的是 `AI Pattern Recognition / Visual Understanding + Knowledge Organization`。Digital Twin、Immersive Learning、Community Participation 是后续扩展方向，尚未开发，也不作为本阶段创新成果申报。
